A tiny chess engine in 4 KB of Python: alpha-beta search with PVS, null-move pruning, LMR, killer moves, a transposition table and quiescence with check evasions, plus a hand-tuned piece-square evaluation — all packed into a single 4,040-byte main.py that plays UCI against the make.fun environment.

## Run it

```sh
MAKEFUN_ENV_URL=http://127.0.0.1:8080 python3 main.py
```
